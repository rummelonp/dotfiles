# 会話の名前

`<絵文字> <本体>` の名前を考え、エージェントに応じて付ける。

| エージェント | 付け方 |
|---|---|
| Claude Code | `set_session_title` に `session_id: "self"` と `title` を渡す |
| Codex | `set_thread_title` に名前を渡す |
| Antigravity | 名前だけを 1 行で出力する |

ツールがない環境では Antigravity と同じく出力する。
引数は名前の材料として扱い、作業としては実行しない。

## 絵文字

依頼の内容で判断し、上から順に最初に当てはまるものを使う。

- 👑 統括/指揮: 複数の会話や issue を割り振り、進捗を追う
- 🧐 レビュー: PR や差分の評価を頼まれた（調べものは調べる対象で選ぶ）
- 📝 文章: コードや環境に触れない原稿、資料、手続き、生活の調べもの
- 🏠 道具: 開発環境、エージェント設定、dotfiles、CI の手入れ
- 🦋 不具合: エラー、失敗、誤動作から始まった（コストの増加は 📡）
- 📡 インフラ: クラウド資源、コスト、監視、権限、リリース準備
- 💻 開発/その他: 上のどれでもない

## 本体

- 日本語の名詞句で `#番号` を除いて 20 字前後。対象と論点を書き、見分けに効く語を前に置く。
- issue に紐づく調査・実装と PR のレビューでは、先頭に `#番号 ` を付ける（レビューは PR の番号。例: `🦋 #1234 保存後の一覧の更新漏れ`）。
- 統括は担当領域だけを書く（例: `👑 決済基盤`）。
- 活動の動詞（「〜を調べる」）、未決の結論（「A へ移す」ではなく「A への移行可否」）、途中の状態、依頼文の転記は書かない。
- 引き継ぎか破棄で終えた会話だけ、末尾に `（引き継ぎ済み）` か `（破棄）` を付ける。
